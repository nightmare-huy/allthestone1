All The Stone 1 - optional resource pack
========================================
The pack itself does not need a resource pack. This folder only contains an
example icon model (asset id: allthestone1:stone_age) if you ever want to give
the "Stone Age" chapter a custom icon:

  1. put a 16x16 png at assets/allthestone1/textures/item/stone_age.png
  2. in FTB Quests, set the chapter icon to allthestone1:stone_age
     (chapter icon field accepts any item/asset id)

Kept out of the mods/ and kubejs/ folders on purpose, so it can be dropped into
<instance>/resourcepacks/ without affecting a server.
